Separation of Concerns

The fundamental architectural principle: what reasons vs. what computes vs. what enforces

Reasoning (Agent / LLM)

Interpret methodology playbook
Decide which tool to invoke next
Generate narrative from metrics
Explain patterns and risks
Non-deterministic output
Bounded by methodology, not code

Deterministic (Tools / Code)

Compute headcount metrics
Calculate tenure statistics
Generate charts (matplotlib)
Render HTML report (Jinja2)
Same input → same output
Unit-tested, version-controlled

Security (Infrastructure)

S3 prefix isolation (client/run)
IAM policy enforcement
No public S3 access
TLS-only bucket policy
Sandbox for dynamic code
Prompts are NOT a boundary

Design Principles

Architectural constraints that shape every decision

Deterministic ≠ Generative
Tools compute metrics reproducibly. The agent interprets them. These are distinct stages with distinct guarantees.
Prompts Are Not Security
Data isolation, code immutability, and execution sandboxing are enforced by IAM/infrastructure, never by instructions to the LLM.
Run Isolation by Construction
Every artifact resolves under {client_id}/{run_id}. The storage interface makes cross-access structurally impossible.
Methodology Guides, Doesn't Cage
Playbooks preserve reasoning space. They are not rigid DAGs. The agent retains judgment within bounded scope.
Reproducible Provenance
Every report stamps: run_id, client_id, methodology version, code version, model ID, timestamps.
Infrastructure as Code
All durable resources defined in CloudFormation. No manual console-only resources. Drift-free by design.

Migration Path to Production

V0 architecture is designed to port cleanly to AgentCore Runtime

V0 → AgentCore Runtime
Tool definitions map directly to AgentCore tool schemas. Agent loop parallels AgentCore's managed runtime. No rearchitecting needed.
V0 → Code Interpreter
Dynamic code execution sandboxing. Currently tools are static; Code Interpreter adds safe ad-hoc computation within runs.
Sandbox → Production
Review provider_data_share, create least-privilege execution roles, disable detailed logging, validate IAM scoping per client.
V0 → Real Methodology
Replace thin_slice.md with full consulting playbook. Add more tools. Quality evaluators layer on without redesign.
